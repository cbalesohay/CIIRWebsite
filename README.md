# CIIRWebsite
Website for the University of Idaho's Center For Intelligent Industrial Robotics

Code is requested to be private 

This project was assigned to me to learn, build, and deploy a React website for CIIR. The educational outcomes of this assignment has been the learning and integration of React, React Bootstrap, Vite, Google Maps API, EmailJs, React-icons and the deployment on Amazon Web Services (AWS) Amplify.
